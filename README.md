# AI Predictive Maintenance System

An AI-based predictive maintenance system for industrial equipment failure prediction.

## Objective

The system analyzes equipment sensor and operational data to predict potential equipment failures before they occur.

## Features

- Data preprocessing
- Exploratory data analysis
- Machine learning-based failure prediction
- Equipment health monitoring
- Failure alerts
- Maintenance recommendations
- Interactive dashboard

## Dataset

AI4I 2020 Predictive Maintenance Dataset.

## Technology Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit
